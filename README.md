# Excel Dental of Moon Township

Static website based on the Excel Dental of Wexford template, using the Moon Township practice information and color palette.

Run `python3 -m http.server 8000 --bind 127.0.0.1` from this directory and open `http://localhost:8000` to preview locally. Appointment links call the office; no online booking service is configured.

Office information was sourced from indexed pages of the existing site because the site was unavailable during development. Confirm contact details, hours, services, and doctors before deployment.
